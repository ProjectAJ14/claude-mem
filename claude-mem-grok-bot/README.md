# claude-mem for Grok Bot

Install from the Grok Bot or Cursor plugin store as **claude-mem-grok-bot**. Does not install Cursor.

Grok Bot has no hooks. After install: `npx claude-mem install --ide grok-bot` for a local worker plus the host-login observer, which drives the logged-in Grok agent over a local loopback shim — no account and no API key. Set `CLAUDE_MEM_MCP_TOKEN` for remote MCP.
